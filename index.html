MidiHelp

Doctor Appointment System

⚙️ Setup Required

Your MidiHelp application is ready! This is a full-stack PHP application that requires a server environment to run.

✨ Key Features

  • Search and filter verified doctors
  • Dynamic appointment booking with real-time slot selection
  • Secure patient authentication
  • Patient dashboard with appointment history
  • Admin panel for doctor and appointment management
  • Mobile-responsive design

🚀 How to Run

Option 1: Using XAMPP/WAMP/MAMP

1. Clone this repository to your server root (htdocs/www/midihelp)

2. Import the SQL file: database/doctor_appointment.sql into phpMyAdmin

3. Visit: http://localhost/midihelp/

Option 2: Using PHP Built-in Server

1. Navigate to the project folder

2. Run: php -S localhost:8000

3. Visit: http://localhost:8000/
